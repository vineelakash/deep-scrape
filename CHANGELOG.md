# Changelog

All notable changes to DeepScrape are documented in this file.

## [1.0.0] - 2026-09-28

### Initial Release — DeepScrape
- **Refactoring & Rebranding**: Transformed the codebase into DeepScrape (`deep_scrape`), an autonomous multi-platform scraping and web intelligence engine for AI agents.
- **Pure English**: 100% translated and modernized all CLI messages, diagnostic doctor reports, channel drivers, and reference guides into clean, professional English.
- **16 Unified Channels**: Comprehensive drivers for LinkedIn, Twitter/X, Reddit, GitHub, YouTube, Facebook, Instagram, XiaoHongShu, Bilibili, V2EX, Xueqiu, Xiaoyuzhou, RSS, and Web.
- **Robust Security**: Enforced owner-only file permissions (`0600`), masked secret prompts, sanitized URI logs, and strict browser extraction consent boundaries.
- **Agent Skill & MCP**: First-class support for LLM agent integration with MCP server capabilities.
