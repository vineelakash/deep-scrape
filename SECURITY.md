# Security Policy

## Supported Versions
Only the latest release of DeepScrape receives security updates.

| Version | Supported |
|---|---|
| 1.0.x | Yes |

## Reporting Vulnerabilities
If you discover a security issue or vulnerability, please report it privately via GitHub Security Advisories at:
https://github.com/vineelakash/deep-scrape/security/advisories/new

Please include:
- Description of the issue
- Steps to reproduce
- Potential impact
